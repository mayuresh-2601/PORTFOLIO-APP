# CHANGELOG — AI Explain + Live System Panel (Gemini Edition)

This update adds two features to the existing portfolio app without touching any existing
functionality (admin dashboard, project/skill/certificate CRUD, contact form all work exactly
as before).

---

## 1. What was added

### AI Explain (Skills & Certificates)
Click any skill or certificate and get a short, plain-language explanation generated by
Google Gemini (`gemini-1.5-flash` — fast and cheap, the right fit for short explanations).

### Ask AI About Me
A chat box (on the new `/system` page) where visitors can ask questions like "what DevOps
skills does he have?" and get an answer grounded in your actual listed skills — not
hallucinated claims.

### Live System Panel (`/system`)
A new page showing **real, live** metrics pulled from the actual running backend server:
CPU load, memory usage, uptime, Docker/bare-Node environment detection, and the deployed
git commit hash — refreshing every 5 seconds. A terminal-style log panel makes it look and
feel like a real ops dashboard, not a static badge.

## 3. Setup — the only new step

1. Get a **free** Gemini API key: https://aistudio.google.com/app/apikey
2. Open `server/.env` (already has a placeholder line added at the bottom) and replace:
   ```
   GEMINI_API_KEY=your-gemini-api-key-here
   ```
   with your real key.
3. That's it — no new npm packages were needed (the code uses Node's built-in `fetch`,
   available in Node 18+).

**On your hosting provider (Render):**
Add `GEMINI_API_KEY` as an environment variable in the Render dashboard for your backend
service, then redeploy. No changes needed on the Vercel (frontend) side.

## 5. What happens if `GEMINI_API_KEY` is missing or wrong

The two AI endpoints return a `502` with a clear message ("AI explanation is temporarily
unavailable"), and the modal on the frontend shows that message calmly instead of hanging
or crashing. **Every other feature on the site is completely unaffected.**
